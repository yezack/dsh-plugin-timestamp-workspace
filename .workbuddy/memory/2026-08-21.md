## 修复 dsh-plugin-timestamp-workspace 加载失败（loaded without registering）
- 症状：`Failed to load plugins ... bundle /plugins/dsh-plugin-timestamp-workspace/client.js loaded without registering "dsh-plugin-timestamp-workspace" via __ModuleLoader__.load`
- 根因：client 构建产物是纯 ESM（lib/client.mjs, export apply/inject），而 rc.6 client-modules 要求 classic script + `window.__ModuleLoader__.load({id, factory})` 注册，id 必须等于包名。与 2026-08-17 dsh-collaboration 同款问题。
- 修复：新增 `scripts/build-client.mjs`（typescript.transpileModule → CJS + __ModuleLoader__ 外壳，src 无 JSX 故不需 Babel），`exports ./client` 指向 `lib/client.js`；新增 `test/verify-client.mjs` 模拟 loader 验证 id/exports/apply。bundle script = `tsdown && node scripts/build-client.mjs`。
- 参照实现：deepseek-harness-wallet、dsh-better-sidebar 的 lib/client.js（同格式）。
- 部署：已 push GitHub（yezack/dsh-plugin-timestamp-workspace，commit eb3edfb，历史 1065ad6/f168ba5 之上 soft-reset 追加）；已复制 lib/client.js + package.json 到 `~/.dsh/profiles/web/node_modules/dsh-plugin-timestamp-workspace/`（删旧 client.mjs）。
- 待用户：重启 DeepSeek Harness 桌面应用（3080 端口 PID 26896）生效。
